Respaldo de datos

Los datos de esta aplicación se guardan únicamente en este dispositivo (no hay servidor). Programa recordatorios y snapshots automáticos para no perder información.

Vincula un archivo en tu computadora (celular (Android/iPhone) y tablet no lo soportan; solo Chrome o Edge de escritorio). Cada cambio se guardará automáticamente ahí, además de en este dispositivo. Si eliges guardarlo dentro de tu carpeta OneDrive o de una biblioteca de SharePoint sincronizada en tu equipo, el archivo también se subirá solo a SharePoint cuando OneDrive sincronice.
Este navegador/dispositivo no soporta guardado directo en archivo. En celular o tablet, los datos igual se guardan automáticamente en este dispositivo (memoria del navegador); usa el respaldo manual o los snapshots para resguardarlos.
